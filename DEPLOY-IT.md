# Инструкция ИТ‑специалисту — публикация сайта **aksystems.co** (EN)

## Что это
Статический сайт (HTML/CSS/JS), **без бэкенда и без сборки** — заливается «как есть».
Временный предпросмотр (НЕ рабочий адрес — только посмотреть, как должно выглядеть):
~~https://anmiddlton-pixel.github.io/aksystems-co-site/~~ — после заливки на хостинг
этот адрес больше не нужен, все ссылки внутри сайта **относительные** и ведут на `aksystems.co`.

Домен назначения: **aksystems.co** (английская версия сайта).

## Состав пакета
```
index.html      — главная (EN), открывается на КОРНЕ домена
zh/index.html   — китайская версия (中文)
ar/index.html   — арабская версия (العربية, RTL)
tour/           — «Тур по сайту» (гид), EN
zh/tour/        — гид на китайском
ar/tour/        — гид на арабском (RTL)
css/            — стили (используются только страницами блога/кейсов)
js/config.js    — адрес почты для формы заявок (см. раздел «Форма»)
js/main.js      — меню/скролл для страниц блога/кейсов
assets/         — logos, icons, img (фоны/кейсы/контакты), video/data.js (анимация лого)
pages/          — blog/index.html, cases/index.html
README.txt      — краткое техописание
```

## Гид / «Тур по сайту»
Гид **уже входит в этот пакет** и грузится вместе с сайтом — отдельно ничего заливать не нужно.
Кнопка «Тур» на каждой версии сайта — **относительная** ссылка (`tour/`), без внешних адресов,
поэтому после заливки гид открывается по коротким адресам на вашем домене:
- **aksystems.co/tour/** — EN
- **aksystems.co/zh/tour/** — 中文
- **aksystems.co/ar/tour/** — العربية

Эти же адреса можно давать как самостоятельную ссылку на гид.

## Вариант 1 — на своём хостинге (основной)
1. Распаковать архив и залить **всё содержимое папки** в корень сайта (`public_html` / `www` / `htdocs`).
   `index.html` должен лежать в корне, чтобы открывался по `https://aksystems.co/`.
2. **DNS** (у регистратора домена aksystems.co):
   - `A` запись `@` → IP вашего сервера;
   - `CNAME` `www` → `aksystems.co` (или `A` `www` на тот же IP).
3. **HTTPS**: выпустить SSL‑сертификат (Let's Encrypt / панель хостинга), включить
   принудительный HTTPS и редирект `http → https`.
4. Проверить, что сайт открывается и все ресурсы грузятся.

## Вариант 2 — GitHub Pages (сайт уже развёрнут там)
Репозиторий: `anmiddlton-pixel/aksystems-co-site`, ветка `main`, Pages включён.
Чтобы повесить на реальный домен:
1. **Settings → Pages → Custom domain** → указать `aksystems.co`, отметить **Enforce HTTPS**.
2. **DNS** у регистратора:
   - apex `@` → четыре `A`‑записи GitHub Pages:
     `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`;
   - `www` → `CNAME` `anmiddlton-pixel.github.io`.
3. Дождаться проверки домена и выпуска сертификата (обычно до ~1 часа).
Обновления в этом варианте: новый commit в `main` → Pages пересобирается автоматически.

## ⚠️ ОБЯЗАТЕЛЬНО: активация формы заявок (иначе заявки не приходят)
Форма **«Get in touch»** отправляет заявки на **info@aksystems.co** через сервис **FormSubmit.co**.
Требуется **разовая активация**:
1. После публикации отправить одну тестовую заявку через форму на боевом домене.
2. На `info@aksystems.co` придёт письмо от FormSubmit со ссылкой активации —
   перейти по ней один раз (**проверить и папку «Спам»**).
3. После этого заявки приходят автоматически.
Адрес получателя настраивается в `js/config.js` (`window.FORM_EMAIL = "info@aksystems.co"`).
(На будущее форму можно переключить на Bitrix24‑вебхук — параметр `window.BITRIX_WEBHOOK`.)

## Внешние зависимости

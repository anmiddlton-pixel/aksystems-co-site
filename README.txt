САЙТ AKCO — статический сайт для размещения на сервере
=======================================================
Корпоративный сайт концерна AKCO — позиционирование «Concerto for Industry»
(концерн, 9 бизнес-доменов, экосистемы AK.Family, метод 4CO).
Три языка в одном пакете: EN (англ.) + 中文 (кит.) + العربية (араб., RTL).
Домен: aksystems.co.

Главная инструкция для ИТ — файл DEPLOY-IT.md (DNS, HTTPS, активация формы,
адреса гида, чек-лист сдачи). Этот README — краткое техописание.

СОДЕРЖИМОЕ
----------
index.html            — главная (EN), открывается на корне домена
zh/index.html         — китайская версия (中文)
ar/index.html         — арабская версия (العربية, справа-налево)
tour/                 — «Тур по сайту» (интерактивный гид), EN
  index.html          — сам гид
  img/                — изображения гида (ОБЩИЕ для всех 3 языков)
zh/tour/index.html    — гид на китайском
ar/tour/index.html    — гид на арабском (RTL, фото отзеркалены)
css/                  — стили (для страниц блога/кейсов)
js/
  config.js           — почта для заявок с формы (см. «ФОРМА» ниже)
  main.js             — меню/скролл для страниц блога/кейсов
assets/
  icons/              — favicon и логотип-иконка
  logos/              — логотип AKCO (SVG)
  video/data.js       — данные морфинг-анимации логотипа в hero
  img/                — изображения сайта (фоны секций, кейсы, контакты)
pages/
  blog/index.html     — лента блога
  cases/index.html    — лента кейсов

РАЗМЕЩЕНИЕ
----------
1. Это обычный статический сайт (HTML/CSS/JS), без бэкенда и сборки.
2. Загрузить ВСЁ содержимое папки в корень сайта (public_html / www / htdocs),
   сохранив структуру папок (zh/, ar/, tour/ и т.д.).
3. index.html должен открываться на корне домена (https://домен/).
4. Подключить домен к хостингу как обычно (A-запись / привязка в панели).
5. Рекомендуется HTTPS (SSL-сертификат) — сайт использует внешние ресурсы по https.

Адреса после размещения:
  aksystems.co/            — EN,  /zh/ — 中文,  /ar/ — العربية
  aksystems.co/tour/       — гид EN,  /zh/tour/ — кит.,  /ar/tour/ — араб.
Переключатель языков и кнопка «Тур» работают по относительным ссылкам —
отдельно ничего настраивать не нужно.

ГИД / «ТУР ПО САЙТУ»
-------------------
- Открывается кнопкой «Тур» на каждой версии сайта и по прямым адресам выше.
- Входит в этот же пакет, грузить отдельно не нужно.
- Картинки вынесены в общую папку tour/img/ (одна на все 3 языка) — страницы
  гида лёгкие (~0.4 МБ), фото кешируются и подгружаются в фон.

ВНЕШНИЕ ЗАВИСИМОСТИ (нужен интернет у посетителя)
------------------------------------------------
- Шрифт Montserrat подключается с Google Fonts (CDN) через <link>.
- На арабской версии дополнительно подключается Noto Sans Arabic (Google Fonts).
  При желании шрифты можно локализовать позже — на работу это не влияет.

ФОРМА ЗАЯВКИ («Ready to discuss your task?»)
--------------------------------------------
- Заявки уходят на почту info@aksystems.co через сервис FormSubmit.co.
- Почта задаётся в js/config.js (строка: window.FORM_EMAIL = "info@aksystems.co").
- ВАЖНО: сервис FormSubmit требует ОДНОРАЗОВОЙ активации адреса.
  При первой отправке формы на info@aksystems.co придёт письмо со ссылкой —
  по ней надо один раз перейти (проверить и папку «Спам»). После этого
  заявки приходят автоматически.
- Чтобы поменять почту — отредактировать js/config.js.
- Позже форму можно переключить на Bitrix24 (входящий вебхук) вместо почты.

ПРИМЕЧАНИЯ
----------
- Правки между языками не переносятся автоматически: шапка/подвал/меню
  продублированы в каждой версии.
- В шаблоне блога есть ссылка на article-slug.html (карточка статьи) —
  это заготовка, страница появится при наполнении блога.
- Все пути относительные — сайт работает и локально (двойной клик по index.html),
  и с любого домена/поддиректории.
